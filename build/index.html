ATARI 2600 → C64

Atari 2600 games ported to the Commodore 64. Build them from your own cartridge ROMs. Everything happens in this page; nothing is uploaded.

Drop a 2600 ROM and the game's profile here The ROM as .a26 (or the .zip it came in), and the profile as .json. Together, or one after the other; its README (.md) too, to read it here. Or click to choose files.

Download .prg Download .d64 disk Download .crt cartridge Download all (.zip)

Open any of them in an emulator such as VICE, or on a real C64 load from disk and RUN (LIST first shows the credits). The .crt is an EasyFlash cartridge image: it starts the game straight away on an EasyFlash, a Kung Fu Flash, an Ultimate 64 or 1541 Ultimate, or in VICE (attach it as a cartridge).

The source holds everything that makes this C64 version, to build it or change it (its CLAUDE.md explains it all): the port's own code and tools, and the original game's program as a disassembly, made here in your browser from your ROM. Your ROM never leaves your computer, and this site holds none of the original game's code.

Supported games

Each needs one exact cartridge dump, recognised by its MD5. The number beside each game is the version of its C64 port. Click a game for details.

Profiles are plain data files: they hold a port's C64 code with every byte of the original game blanked out, so they're safe to share. Your ROM, checked by MD5, fills the gaps.
